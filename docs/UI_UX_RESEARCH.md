# UI/UX 调研（2026-09）

方法：联网访问与复核各产品当前版本的公开界面与设计资料，学习设计原则而非克隆视觉。

| 产品 | 观察面 | 值得学习 | 不照搬 |
|---|---|---|---|
| Linear | 工作区、命令面板、列表密度 | 中性灰阶+单一强调色；键盘可达性；信息密度高而不挤 | 全键盘工作流对中学生过重 |
| Notion | 文档层级、空状态 | 安静的排版、块级结构、空状态给"下一步" | 无限嵌套自由度（学习平台需要固定闭环） |
| Khan Academy | 学习路径、进度反馈 | 步骤化学习闭环的叙事；掌握度用「进度」而非分数恐吓 | 卡通插画风格 |
| Quizlet | 卡片学习、集组 | 组题/复习的组织方式 | 广告位与付费墙布局 |
| Brilliant | 交互式推导 | 把"方法"拆成可点击的步骤；留白节奏 | 高饱和配色 |
| Duolingo | 每日任务、连续天数 | 今日任务卡片的"为什么/多久"透明度；轻量激励 | 过度游戏化（streak 焦虑） |
| Readwise Reader | 阅读流 + 高亮回顾 | "稍后回顾"的时间调度思想；回顾邮件式摘要 | 阅读器形态本身 |
| Apple Education / Classroom | 清晰层级、系统字体排印 | 字层级节制（每屏最多三级）、聚焦单任务 | macOS 专属控件 |

## 采用结论

1. **三模块闭环是主视觉**：Dashboard 首屏即「课堂 → 练习 → 巩固 ↺」节点图（本次实现）。
2. 中性暖白底 + 单一深青品牌色 + 琥珀仅作优先级信号（Linear×Khan 的混合）。
3. 复习卡片必须回答三件事：**为什么现在复习 / 预计保持率 / 大概多久**（Duolingo 的透明度）。
4. 知识点树采用"点击节点 → 右侧详情"双栏（Brilliant 的步骤感 + Linear 的面板）。
5. 所有 AI 产出均给「来源/估算」标注（Readwise 的 groundings 思路）：笔记可跳回时间戳、掌握度标注"估算"。
6. 空状态一律给下一步动作按钮（Notion）。
